- **Background Canvas**: Cool ice-slate white (`#F1F4F9`) with fine architectural vertical lines.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open `http://localhost:3000` in your browser.

### 3. Build for Production
```bash
npm run build
```
